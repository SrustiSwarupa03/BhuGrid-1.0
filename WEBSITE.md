## Purpose

The showcase website is BhuGrid's **public-facing explanatory and presentation site**. It is distinct from the React functional GIS application.

Its purpose is to explain the BhuGrid challenge, solution, intended audiences, principal features and prototype scope, and direct visitors to the application and relevant project documentation.

## Website content and implementation

The `website` branch contains a `showcase/` directory with HTML pages including `index.html`, `about.html`, `problem.html`, `solution.html`, `features.html`, `map.html`, `tourist.html`, `admin.html` and `handbook.html`, plus stylesheet and visual assets.

The homepage source includes a link to the functional web app. The website presents information about the GIS platform and its public, tourism, inspection and administrative use cases; it does not itself replace secured operational workflows.

## Presentation and credibility guidelines

- Explain that BhuGrid 1.0 is a **controlled DEMO prototype**.
- Do not describe unverified OSM institutions as officially certified.
- Do not portray fictional property records as actual government land/property records.
- Do not claim successful live nearby-service search while Overpass data retrieval remains unresolved.
- Present AI suggestions as advisory and human-reviewed.
- Avoid describing synthetic image comparisons as real-world encroachment detection.
